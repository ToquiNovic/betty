## ⚡ Conecta tus Dispositivos en Segundos

Publica telemetría estándar desde cualquier lenguaje o microcontrolador con una sola línea de comando o script:

<Tabs>
  <TabItem label="cURL / CLI" icon="terminal">
```bash
mosquitto_pub \
  -h localhost -p 1883 \
  -u "4c40ea57-43e0-4ee2-a8d5-77aae4fc387b" \
  -P "betty_live_xxxxxxxxxxxxxxxxxxxxxxxx" \
  -t "betty/sensor/4c40ea57-43e0-4ee2-a8d5-77aae4fc387b/data" \
  -m '{"temperature": 24.5, "humidity": 60.2, "origin_type": "sensor"}'
```
  </TabItem>
  <TabItem label="ESP32 (C++)" icon="laptop">
```cpp
#include <PubSubClient.h>
#include <ArduinoJson.h>

StaticJsonDocument<128> doc;
doc["temperature"] = 24.5;
doc["humidity"] = 60.2;
doc["origin_type"] = "sensor";

char buffer[128];
serializeJson(doc, buffer);
client.publish("betty/sensor/UUID/data", buffer);
```
  </TabItem>
  <TabItem label="Python" icon="document">
```python
import paho.mqtt.client as mqtt, json

client = mqtt.Client()
client.username_pw_set("SENSOR_UUID", "betty_live_...")
client.connect("localhost", 1883)

client.publish("betty/sensor/SENSOR_UUID/data", json.dumps({
    "temperature": 24.5, "humidity": 60.2, "origin_type": "sensor"
}))
```
  </TabItem>
  <TabItem label="TypeScript / Node.js" icon="code">
```typescript
import mqtt from 'mqtt';

const client = mqtt.connect('mqtt://localhost:1883', {
  username: 'SENSOR_UUID',
  password: 'betty_live_...',
});

client.publish('betty/sensor/SENSOR_UUID/data', JSON.stringify({
  temperature: 24.5, humidity: 60.2, origin_type: 'sensor'
}));
```
  </TabItem>
</Tabs>

## 🌟 Pilares de la Plataforma

<CardGrid stagger>
  <Card title="Ingesta MQTT de Alto Throughput" icon="rocket">
    Broker **EMQX 5.8** con autenticación criptográfica vía API Keys por dispositivo (`betty_live_...`) y soporte para miles de mensajes por segundo.
  </Card>
  <Card title="Soporte Físico + Metaversos" icon="laptop">
    Clasifica telemetría como `sensor` (dispositivo físico real) o `metaverso` (entorno virtual o simulación 3D) en un mismo flujo unificado.
  </Card>
  <Card title="Series Temporales Hiper-Escalables" icon="document">
    Respaldado por **PostgreSQL 16 + TimescaleDB** (hypertables con particionamiento temporal) y caché ultra rápida en **Dragonfly**.
  </Card>
  <Card title="Flasheo de Firmware por Web Serial" icon="setting">
    Instala binarios de microcontroladores (.bin) directamente desde el navegador por USB con `esptool-js` y visualiza modelos 3D (.glb, .stl).
  </Card>
</CardGrid>
