## ⚡ Connect Your Devices in Seconds

Publish standard telemetry from any programming language or microcontroller in minutes:

<Tabs>
  <TabItem label="cURL / CLI" icon="terminal">
```bash
mosquitto_pub \
  -h localhost -p 1883 \
  -u "4c40ea57-43e0-4ee2-a8d5-77aae4fc387b" \
  -P "betty_live_xxxxxxxxxxxxxxxxxxxxxxxx" \
  -t "betty/sensor/4c40ea57-43e0-4ee2-a8d5-77aae4fc387b/data" \
  -m '{"temperature": 24.5, "humidity": 60.2, "origin_type": "sensor"}'
```
  </TabItem>
  <TabItem label="ESP32 (C++)" icon="laptop">
```cpp
#include <PubSubClient.h>
#include <ArduinoJson.h>

StaticJsonDocument<128> doc;
doc["temperature"] = 24.5;
doc["humidity"] = 60.2;
doc["origin_type"] = "sensor";

char buffer[128];
serializeJson(doc, buffer);
client.publish("betty/sensor/UUID/data", buffer);
```
  </TabItem>
  <TabItem label="Python" icon="document">
```python
import paho.mqtt.client as mqtt, json

client = mqtt.Client()
client.username_pw_set("SENSOR_UUID", "betty_live_...")
client.connect("localhost", 1883)

client.publish("betty/sensor/SENSOR_UUID/data", json.dumps({
    "temperature": 24.5, "humidity": 60.2, "origin_type": "sensor"
}))
```
  </TabItem>
  <TabItem label="TypeScript / Node.js" icon="code">
```typescript
import mqtt from 'mqtt';

const client = mqtt.connect('mqtt://localhost:1883', {
  username: 'SENSOR_UUID',
  password: 'betty_live_...',
});

client.publish('betty/sensor/SENSOR_UUID/data', JSON.stringify({
  temperature: 24.5, humidity: 60.2, origin_type: 'sensor'
}));
```
  </TabItem>
</Tabs>

## 🌟 Platform Pillars

<CardGrid stagger>
  <Card title="High-Throughput MQTT Ingestion" icon="rocket">
    Powered by **EMQX 5.8** with per-sensor cryptographic HTTP authentication (`betty_live_...`) supporting thousands of messages per second.
  </Card>
  <Card title="Hardware + Metaverse Support" icon="laptop">
    Classify telemetry as `sensor` (physical hardware) or `metaverso` (virtual 3D simulation) within a unified pipeline.
  </Card>
  <Card title="Hyper-Scalable Time Series" icon="document">
    Backed by **PostgreSQL 16 + TimescaleDB** (time-partitioned hypertables) and multi-threaded in-memory caching via **Dragonfly**.
  </Card>
  <Card title="Web Serial USB Firmware Flashing" icon="setting">
    Install compiled binary firmware (.bin) directly from the browser over USB with `esptool-js` and explore 3D CAD models (.glb, .stl).
  </Card>
</CardGrid>
