---
title: Roles and Permissions (RBAC)
description: Unified relational role-based access control for platform and team workspaces.
---

## 🏛️ 1. System Roles (`scope: system`)

- `admin`: Full platform control, user management, and system auditing.
- `user`: Standard user with personal sensor and dashboard creation rights.

---

## 👥 2. Team Roles (`scope: team`)

- `owner`: Full workspace control, billing/deletion, member management.
- `team_admin`: Manage shared sensors, dashboards, and invitations.
- `member`: Access shared devices, build dashboards, stream data.
- `viewer`: Read-only observer.
